# 技术选型与架构

状态：待需求确认  
版本：0.1

## 设计原则

- 现场可靠性优先
- 控制指令可追踪、可确认、可恢复
- 危险操作具备防误触机制
- 核心播控不依赖公网
- UI 状态必须区分“期望状态”和“设备实际状态”

## 待决策项

### 应用形态

待比较：Windows 桌面端、浏览器控制台、桌面壳 + Web UI、多端架构。

### 播放与控制边界

待确认：本软件直接解码/播放，或仅作为现有硬件和媒体服务器的统一控制层。

### 通信与协议

需根据设备清单评估：HTTP/WebSocket、OSC、MIDI、Art-Net/sACN、串口、厂商 SDK 或其他协议。

### 数据与配置

待定义：素材元数据、节目单、场景、设备配置、用户权限、日志和备份策略。

### 可靠性

待定义：心跳、超时、重试、幂等、状态校准、离线降级、崩溃恢复和紧急模式。

## 候选模块

- 控制台 UI
- 播控编排服务
- 设备适配层
- 素材与节目管理
- 状态同步与事件总线
- 本地持久化
- 日志、诊断与告警

最终模块边界将在设备与核心流程确认后确定。
