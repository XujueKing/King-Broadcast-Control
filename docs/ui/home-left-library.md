# `UI-R02 / L` 首页曲库与歌单

状态：已确认

版本：1.0

## 1. 区域用途

首页的 `UI-R02 / L` 是现场操作用的曲库/歌单区域，用于给 Deck 1 或 Deck 2 查看歌单、选择候选歌曲。它不是音乐素材管理页面。

首页 L 区明确不显示：

- 搜索框
- 上传素材
- 新建歌曲或新建歌单
- 批量管理
- 删除、重命名、文件整理等管理按钮

上述功能仅在底部导航的“音乐管理”页面提供。

## 2. 纵向布局

```text
┌────────────────────────────────┐
│ 1号曲库          2号曲库       │  顶部 Deck 切换
├────────────────────────────────┤
│                                │
│ 对应歌单的歌曲列表             │  中部列表
│ 当前播放行高亮                 │
│ 候选/待播状态                  │
│                                │
├────────────────────────────────┤
│ 周一 周二 周三 周四 周五 周六 周日 │  常规歌单按钮
│ 情人节  活动  其他特别歌单…    │  预设歌单按钮
└────────────────────────────────┘
```

顶部和底部固定，中部歌曲列表独立滚动。列表滚动不能让 Deck 切换按钮或歌单按钮消失。

## 3. 顶部 Deck/曲库切换

固定显示两个等宽按钮：

| 编号 | 显示文字 | 对应对象 |
| --- | --- | --- |
| `LIB-01` | 1号曲库 | Deck 1 的候选/播放列表视图 |
| `LIB-02` | 2号曲库 | Deck 2 的候选/播放列表视图 |

交互规则：

- 切换按钮只改变 L 区当前操作目标，不影响正在播放的 Deck
- 当前选择使用绿色边框、图标和轻微半透明背景
- 如果某 Deck 正在播放，其按钮同时显示 `ON AIR`
- 如果某 Deck 已装载候选，其按钮显示 `READY`
- `ON AIR` 和当前选中是两种状态，可以同时出现在不同按钮上
- UI 保留“1号曲库/2号曲库”文字；数据层实际复用统一歌曲库，分别维护两个 Deck 的运行队列，不复制媒体文件

## 4. 底部歌单按钮

第一行固定为 7 个常规歌单：

- `PL-W1` 周一
- `PL-W2` 周二
- `PL-W3` 周三
- `PL-W4` 周四
- `PL-W5` 周五
- `PL-W6` 周六
- `PL-W7` 周日

第二行显示特别歌单预设，例如：

- `PL-S01` 情人节
- `PL-S02` 活动
- 其他已发布的节日、主题夜和包场歌单

规则：

- 点击按钮后，中部立即切换为对应已发布歌单
- 当前歌单按钮使用绿色选中态
- 当天星期按钮可显示弱提示，但不强制切换
- 特别歌单数量增加时使用横向滚动/“更多”弹层，不压缩周一到周日按钮文字
- 首页只选择已发布歌单，不在此新建、重命名或删除
- 切换浏览歌单不自动替换正在播放队列；装载或应用时需要明确操作

## 5. 中部歌曲列表

列表优先显示现场选择需要的信息：

| 字段 | 必须显示 |
| --- | --- |
| 序号 | 是 |
| 歌名 | 是 |
| 歌手 | 是 |
| 时长 | 是 |
| 视频状态 | 是，以紧凑图标/文字显示 |
| 灯光预设 | 是，以紧凑图标/名称显示 |
| 原声/伴唱能力 | 是，以状态图标显示 |
| Deck 状态 | 是：ON AIR / READY / 未装载 / 错误 |

行操作保持简单：

- 单击选中歌曲
- 双击或“装载”按钮把歌曲装入当前选中的 1号/2号 Deck
- 当前播放歌曲不允许因误双击而重新加载
- 右键/更多菜单只保留现场需要的“装载、设为下一首、查看详情”

## 6. 当前播放高亮

当前播放行必须明显，但适合暗场：

- 使用半透明翡翠绿背景，例如 `rgba(53, 208, 127, 0.14)`
- 左侧增加 3–4 px 绿色高亮条
- 显示 `ON AIR` 文字和播放图标
- 歌名使用主要文字色，不使用大面积高亮绿文字
- 鼠标 Hover 不能覆盖或混淆 ON AIR 状态
- 若当前歌曲不属于正在浏览的歌单，在列表顶部显示一条紧凑的“当前播放”摘要，不伪造到当前歌单中

待播歌曲使用更弱的绿色/边框并显示 `READY`；普通选中行使用中性深色，避免与 ON AIR 混淆。

## 7. 与 C2 的联动

- L 顶部选择 1号曲库时，歌曲装载目标为 C2 的 Deck 1
- L 顶部选择 2号曲库时，歌曲装载目标为 C2 的 Deck 2
- C2 的 Deck 状态变化实时反映到 L 顶部按钮和歌曲行
- Crossfader 切换完成后，新的 ON AIR 行自动高亮，但不强制滚动打断操作员当前浏览；提供“定位当前播放”按钮
