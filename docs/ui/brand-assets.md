## KING CLUB Logo

- 正式文件：[king-club-logo-white.svg](../../assets/brand/king-club-logo-white.svg)

- 原始画布：51.1 × 27.4
- 默认颜色：白色
- 默认位置：`UI-R01 / T` 左侧

使用规则：

- 保持原始宽高比，不拉伸、不压缩
- 不修改路径造型
- 不添加描边、阴影、渐变或发光
- 深色控制台使用白色版本
- Logo 与 `Broadcast Control` 产品标题分开布局，标题不是 Logo 的组成部分
- 实现时直接引用 SVG 文件，不转成低分辨率位图
