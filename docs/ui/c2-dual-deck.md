# `UI-R04 / C2` 双 Deck 播放控制

状态：已确认

版本：1.0

## 1. 区域用途

`UI-R04 / C2` 固定为双 Deck 实时播放与无缝衔接区。区域同时展示：

- 当前播放和待播歌曲
- 歌曲对应的视频画面/缩略图
- 当前绑定的灯光预设
- 播放进度、已播放时间和剩余时间
- Deck 1 与 Deck 2 的加载、待播、播放和错误状态
- 两首歌曲之间的 Crossfader 与自动衔接状态

## 2. 布局

```text
┌───────────────────────┬─────────────┬───────────────────────┐
│ Deck 1                │  Transition │ Deck 2                │
│ 歌曲 / 视频 / 灯光    │             │ 歌曲 / 视频 / 灯光    │
│ 进度 / 时间 / IN-OUT  │ Crossfader │ 进度 / 时间 / IN-OUT  │
│ 播放控制 / 状态       │ Auto/Manual │ 加载候选 / 播放控制   │
└───────────────────────┴─────────────┴───────────────────────┘
```

- Deck 1 和 Deck 2 左右对称
- 中间过渡区宽度小于两侧 Deck，放置 Crossfader、自动/手动模式和过渡倒计时
- 当前 Deck 显示 `ON AIR`，待播 Deck 显示 `READY`；不能只靠绿色区分
- 哪个 Deck 当前播放不固定，切换完成后两边角色互换

## 3. 单个 Deck 显示内容

- 歌曲名、歌手和歌曲来源
- 视频缩略图及画面来源：原 MP4、自有视频或默认背景
- 灯光预设名称及连接/触发状态
- 当前原声/伴唱状态
- 波形或简化时间轴
- 当前时间、总时长和剩余时间
- `IN` 开始点、`OUT` 混出点
- 播放、暂停、CUE、重新加载和卸载
- 候选歌曲装载状态；实际歌曲选择由首页 L 区完成

## 4. 候选歌曲流程

1. 一个 Deck 正在 `ON AIR`。
2. 操作员在首页 L 区选择另一个 Deck 对应的 1号/2号曲库。
3. 从当前已发布歌单中选择并装载候选歌曲。
4. 系统检查音频、视频、灯光和 IN/OUT 点，完成解码预热。
5. 待播 Deck 显示 `READY` 后才能进入自动衔接。
6. 操作员可随时更换候选，不影响当前 Deck 播放。

首页不提供歌曲搜索、上传或新建。搜索整个本地音乐库属于“音乐管理”页面；首页候选选择统一在 L 区当前歌单中完成。

## 5. 无缝衔接

每首歌保存两个混音标记：

- `IN`：新歌曲真正开始参与播放的位置，可跳过不需要的前奏或空白
- `OUT`：旧歌曲开始交给下一首的位置，可跳过不需要的结尾或长尾

自动衔接过程：

1. 当前 Deck 到达 `OUT` 点。
2. 待播 Deck 从 `IN` 点开始播放。
3. 两首歌在设定时间内重叠。
4. Crossfader 使用等功率曲线降低当前 Deck、抬高待播 Deck。
5. 视频按选定方式交叉淡化或切换。
6. 灯光在开始、中点或结束触发下一预设。
7. 过渡完成后，新 Deck 变为 `ON AIR`，旧 Deck 卸载并等待下一个候选。

## 6. 控制项

- Crossfader：手动拖动，位置从 Deck 1 到 Deck 2
- 自动衔接：开启/关闭
- 过渡时间：3 秒、5 秒、8 秒和自定义
- 立即衔接：无需等待 OUT 点，立即执行当前过渡配置
- 取消自动衔接：倒计时期间可以取消
- IN/OUT 编辑：在时间轴上拖动，支持试听后保存到歌曲默认配置
- 条目覆盖：本次歌单可以覆盖歌曲默认 IN/OUT，不影响其他歌单

## 7. 首版边界

- 支持可靠的重叠播放和音量交叉淡化
- 支持人工设置 IN/OUT 点并自动保存
- 可通过静音/低能量检测提出 IN/OUT 建议，但必须允许人工校正
- 首版不承诺自动节拍对齐、变速不变调、搓碟和专业 DJ 效果器
- 没有 BPM 对齐时，系统实现的是平滑无间隙衔接，不宣称专业 DJ 混拍
