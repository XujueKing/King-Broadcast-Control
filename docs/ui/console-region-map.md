## 2. 布局关系

```text
┌──────────────────────────────────────────────────────┐
│ UI-R01 / T                                           │
├──────────────────┬───────────────────┬───────────────┤
│                  │ UI-R03 / C1       │               │
│                  │                   │               │
│ UI-R02 / L       ├───────────────────┤ UI-R05 / R    │
│                  │ UI-R04 / C2       │               │
│                  │                   │               │
├──────────────────┴───────────────────┴───────────────┤
│ UI-R06 / B                                           │
└──────────────────────────────────────────────────────┘
```

层级规则：

- 根布局按纵向分为 `T + 主体 + B`
- 主体按横向分为 `L + C + R`
- 中央 `C` 再按纵向分为 `C1 + C2`
- `T` 和 `B` 始终横跨整个控制台宽度
- `L`、`C1/C2`、`R` 共用同一主体高度

## 3. 初始比例

以下比例依据确认图估算，用作第一版实现起点，不作为不可调整的像素值：

| 尺寸 | 初始比例 |
| --- | --- |
| `T` 高度 | 控制台高度约 5–6% |
| 主体高度 | 使用 T、B 之外的全部可用高度 |
| `B` 高度 | 控制台高度约 5%，采用紧凑型单行导航 |
| `L` 宽度 | 与 R 平分 C 之外的剩余宽度 |
| 中央 `C` 宽度 | 随 `C1` 实际高度联动：8:9 LED 预览宽度 + 左右两条控制栏宽度 |
| `R` 宽度 | 与 L 平分 C 之外的剩余宽度 |
| `C1` 高度 | 中央区域高度目标约 60–64%，相对上一版提高 |
| `C2` 高度 | 中央区域高度目标约 36–40%，相对上一版降低 |

第一版按 1920 × 1080 操作显示器设计。实现时使用 CSS Grid/Flex 比例布局和最小尺寸约束，不把参考图的绝对像素写死。

## 3.1 `UI-R03 / C1` LED 预览约束

`C1` 已确认为 LED 主屏实时预览，用户提供的 T 形比例为正式比例：

- 右侧第一个按钮固定为“预览”模式开关，不再作为摄像机监控按钮；开启后 C1 从单屏扩展为 `PGM 当前上屏 + PVW 待确认` 两个并列的 8:9 屏幕
- 双屏预览开启和关闭时，中央列宽度采用约 340ms 缓动动画变化；L、R 区同步平滑收窄或恢复，两个预览屏不得被拉伸变形
- 双屏开启后的 R 区使用专用紧凑布局：视频、图片和文字素材均改为每行 2 个；灯光预设隐藏中文名称，只保留数字、循环/单次状态和时长。所有内部网格必须 `min-width: 0`，禁止产生横向溢出
- 双屏模式中 PGM 使用绿色状态标识，PVW 使用橙黄色状态标识；素材悬停和锁定只改变 PVW，点击“上屏”后才更新 PGM
- 双屏预览是持续工作台：上屏后 PVW 不关闭、不清空，并保留可继续编辑的独立副本；控制条长期显示“重置 / 上屏”。“重置”只把 PVW 恢复为当前 PGM 的完整快照，不改变 PGM、第二屏和正在播放的媒体时间
- PVW 使用完整的 8:9 矩形素材画布，视频和图片以 `cover` 铺满整个画布；不得对 PVW 素材应用 T 形遮罩。真实 T 形 LED 可视边界仅用清晰红线叠加标示，红线外仍显示素材内容，方便操作员判断最终裁切范围
- PVW 锁定视频或图片素材后显示画面变换工具：拖动画面可上下左右移动；“自由拉伸”允许宽高分别缩放；“等比”保持源比例缩放；“锁宽”以画布宽度为基准同比适配；“锁高”以画布高度为基准同比适配；“重置”恢复居中 cover 满铺
- 红色 T 形可视边界在调节过程中保持固定，变换参数属于具体素材，确认上屏时必须把同一参数应用到 PGM
- 当前正在 PGM 播放的素材也允许再次单击进入 PVW 调节；调节使用独立草稿参数，不得提前改变 PGM。确认后仅热更新位置、拉伸和缩放参数，不重新加载视频、不改变播放时间、不暂停声音且不产生黑帧

- 逻辑外框：2048 × 2304 px
- 外框宽高比：8:9
- 上半 A 区：1024 × 1152 px，水平居中
- 下半 B 区：2048 × 1152 px，铺满下半部分
- 上方左右非显示区：各 512 × 1152 px
- 预览遮罩：[led-main-screen-mask.svg](../../assets/ui/led-main-screen-mask.svg)

布局规则：

- 预览画布始终保持 `aspect-ratio: 8 / 9`，禁止随 `C1` 容器拉伸变形
- `C1` 不设置独立头部状态栏或底部状态栏，避免压缩异形屏预览
- 预览严格保持 8:9，并完整占满其可视容器；可视容器的上、下、左、右四边均不得出现布局留白、内边距或比例补边
- C1 目标提高至中央区域约 60–64%，C2 相应降低；异形 LED 预览必须始终在 C1 可视容器内四边贴合，不得因额外标题、状态栏或留白缩短画面
- 中央列宽必须由 C1 实际可用高度反向计算并实时联动：LED 预览宽度 = C1 可视高度 × 8 / 9，再加左右控制栏宽度；不得先固定中央列宽后在预览四周补空白
- LED 预览左右各设置一条控制栏；控制栏位于 8:9 预览外侧，不挤压或改变异形屏比例
- 左侧控制栏由直线等分为 4 个输出屏幕切换位：主屏、DJ 台条屏、扩展屏幕 1、扩展屏幕 2
- 右侧控制栏由直线等分为 4 个监控机位切换位：舞台、DJ 台、观众区、备用机位
- 左右两侧共 8 个按钮均为可配置入口；按钮短文字、完整名称和状态文字在“设置”页面编辑
- 左侧 4 个按钮还可在“设置”页面编辑对应输出设备及其识别、连接和显示属性
- 右侧 4 个按钮还可在“设置”页面编辑对应视频流地址、协议、认证和连接属性
- 上述 8 个按钮的配置保存到主控电脑本机；应用重启后恢复，不依赖互联网或云端账户
- 点击左侧按钮切回对应屏幕的节目预览；点击右侧按钮切换到相应实时监控画面
- 分辨率、输出、当前视频和当前灯光等操作员状态悬浮放置在 T 形上半部左右两块黑色无 LED 区域，不额外占用预览高度
- 非显示区域使用纯黑，发光区域显示最终合成画面
- 预览必须与 LED 输出复用同一合成状态、遮罩和安全区
- C1 尺寸变化时通过联动中央列宽保持 8:9，不在预览可视容器四周保留剩余空间
- 可在预览上叠加仅操作员可见的边界、安全区和 A/B 区标识；这些辅助线不得出现在 LED 正式输出
- 后续即使 `L`、`R` 或 `C2` 尺寸调整，`C1` 内的 LED 外框比例仍保持 8:9

## 3.2 `UI-R06 / B` 主导航约束

`B` 已确认为全局主导航栏，详细规范见 [底部主导航](bottom-navigation.md)。该区域始终横排 7 个固定顺序按钮，不改为竖排，不与播放控制条混用。

固定顺序为：首页、音乐管理、视频管理、灯光管理、调音台、Avolites Tiger Touch Pro、设置。

视觉和尺寸规则：

- `B` 使用约 5% 的紧凑高度，导航文字保持清晰可读
- 7 个按钮从窗口最左侧到最右侧完整均分，不设置两侧外边距或留白
- 7 个导航按钮等宽横排，并随画布宽度自适应
- 按钮不使用独立圆角卡片、胶囊底或悬浮卡片效果
- 相邻按钮使用简洁直线分割；当前页通过文字、图标和底部/侧边绿色状态线表达，不依赖圆角背景块
- “设置”为第 7 个按钮，也是编辑 C1 左右 8 个按钮及其设备、视频流属性的统一入口

## 3.3 `UI-R04 / C2` 双 Deck 约束

`C2` 已确认为双 Deck 实时播放和无缝衔接区，详细规范见 [C2 双 Deck 播放控制](c2-dual-deck.md)。Deck 1/2 左右并列，中间放置过渡控制；目标高度降低至中央区域约 36–40%，区域高度调整不能把其中一个 Deck 隐藏到分页或弹窗中。

C2 内部的歌曲信息、波形、播放模式、transport 和 Crossfader 必须随区域宽高自适应。内容不得向下溢出或覆盖 Crossfader、`UI-R06 / B`，也不得让 Deck 内容横向侵入中间过渡区；空间不足时应优先收紧间距、缩短次要文字或使用省略，而不是依赖页面级滚动或越界显示。

## 3.4 `UI-R02 / L` 首页曲库约束

`L` 在首页固定为曲库和歌单选择区，详细规范见 [首页曲库与歌单](home-left-library.md)。顶部 Deck 切换和底部歌单按钮固定，中部列表独立滚动；首页禁止出现搜索、上传、新建和批量管理按钮。

L 区标题头采用紧凑单行布局，默认约 40px；图标后紧跟主标题，小字说明靠右，禁止换成两行。

L 区按钮组采用紧凑边距：缩小四周外边距和相邻按钮间距，把空间优先留给曲库内容。

1号/2号曲库下方使用贯穿分割线；周一至周日固定为第一行 7 等分，第二行固定预留 7 个节日与活动歌单位。

L 区向 Deck 1/2 装载歌曲属于候选准备：目标 Deck 进度归零并保持暂停，不能自动播放、移动 Crossfader、切换大厅声音或改变 C1 节目；播放与混音仅由 `UI-R04 / C2` 的操作员手动执行。

## 3.5 `UI-R05 / R` 视频与灯光约束

`R` 在首页上下均分：`UI-R05-A` 为视频快速选择，`UI-R05-B` 为 Tiger Touch 灯光快捷控制。详细规范见 [视频与灯光快捷区](home-right-media-lighting.md)。两个子区域各自滚动，默认高度比例固定为 50/50。

R 区上下两个标题头均采用紧凑单行布局，默认约 38px；图标后紧跟主标题，小字说明靠右，禁止换成两行。

R 区视频缩略图、灯光预设和快捷操作采用紧凑边距，减少按钮四周留白。

## 4. 后续命令格式

以下命令均可准确定位：

- “调整 `UI-R03`，增加主屏预览。”
- “调整 `C1`，预览画面扩大一些。”
- “把 `UI-R06/B` 的控制按钮加高。”
- “交换 `L` 和 `R` 的内容。”

当图片代号和固定编号同时出现但不一致时，以固定编号 `UI-Rxx` 为准，并在修改前指出冲突。
