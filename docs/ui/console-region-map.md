以下编号是后续设计、开发和修改命令的稳定引用，不因区域内容或显示名称调整而改变。

| 固定编号 | 图片代号 | 区域名称 | 位置 | 当前用途 |
| --- | --- | --- | --- | --- |
| `UI-R01` | `T` | 顶部区域 | 全宽顶部 | 左侧显示 KING CLUB Logo 与产品标题；其他内容待指定 |
| `UI-R02` | `L` | 左侧区域 | 主体左栏 | 待后续指定 |
| `UI-R03` | `C1` | 中央上部区域 | 主体中栏上部 | 待后续指定 |
| `UI-R04` | `C2` | 中央下部区域 | 主体中栏下部 | 待后续指定 |
| `UI-R05` | `R` | 右侧区域 | 主体右栏 | 待后续指定 |
| `UI-R06` | `B` | 底部区域 | 全宽底部 | 待后续指定 |

## 2. 布局关系

```text
┌──────────────────────────────────────────────────────┐
│ UI-R01 / T                                           │
├──────────────────┬───────────────────┬───────────────┤
│                  │ UI-R03 / C1       │               │
│                  │                   │               │
│ UI-R02 / L       ├───────────────────┤ UI-R05 / R    │
│                  │ UI-R04 / C2       │               │
│                  │                   │               │
├──────────────────┴───────────────────┴───────────────┤
│ UI-R06 / B                                           │
└──────────────────────────────────────────────────────┘
```

层级规则：

- 根布局按纵向分为 `T + 主体 + B`
- 主体按横向分为 `L + C + R`
- 中央 `C` 再按纵向分为 `C1 + C2`
- `T` 和 `B` 始终横跨整个控制台宽度
- `L`、`C1/C2`、`R` 共用同一主体高度

## 3. 初始比例

以下比例依据确认图估算，用作第一版实现起点，不作为不可调整的像素值：

| 尺寸 | 初始比例 |
| --- | --- |
| `T` 高度 | 控制台高度约 9.5% |
| 主体高度 | 控制台高度约 78% |
| `B` 高度 | 控制台高度约 12.5% |
| `L` 宽度 | 主体宽度约 33% |
| 中央 `C` 宽度 | 主体宽度约 34% |
| `R` 宽度 | 主体宽度约 33% |
| `C1` 高度 | 中央区域高度约 70% |
| `C2` 高度 | 中央区域高度约 30% |

第一版按 1920 × 1080 操作显示器设计。实现时使用 CSS Grid/Flex 比例布局和最小尺寸约束，不把参考图的绝对像素写死。

## 4. 后续命令格式

以下命令均可准确定位：

- “调整 `UI-R03`，增加主屏预览。”
- “调整 `C1`，预览画面扩大一些。”
- “把 `UI-R06/B` 的控制按钮加高。”
- “交换 `L` 和 `R` 的内容。”

当图片代号和固定编号同时出现但不一致时，以固定编号 `UI-Rxx` 为准，并在修改前指出冲突。

## 5. 代码命名约定

后续组件和测试选择器使用固定编号：

| 固定编号 | React 组件建议名 | DOM 标识 |
| --- | --- | --- |
| `UI-R01` | `TopRegion` | `region-top` |
| `UI-R02` | `LeftRegion` | `region-left` |
| `UI-R03` | `CenterPrimaryRegion` | `region-center-primary` |
| `UI-R04` | `CenterSecondaryRegion` | `region-center-secondary` |
| `UI-R05` | `RightRegion` | `region-right` |
| `UI-R06` | `BottomRegion` | `region-bottom` |

每个区域根节点后续添加 `data-region-id="UI-Rxx"`，便于截图测试、自动化测试和问题定位。
