# `UI-R06 / B` 底部主导航

状态：已确认

版本：1.0

## 1. 区域用途

`UI-R06 / B` 固定为控制台全局主导航栏，在所有主页面常驻。导航按钮横向排列，不使用参考图中的竖排方式。

## 2. 固定顺序与编号

| 按钮编号 | 页面标识 | 显示文字 | 建议图标语义 |
| --- | --- | --- | --- |
| `NAV-01` | `home` | 首页 | 房屋/总控台 |
| `NAV-02` | `music` | 音乐管理 | 音符 |
| `NAV-03` | `video` | 视频管理 | 视频/显示器 |
| `NAV-04` | `lighting` | 灯光管理 | 灯光/光束 |
| `NAV-05` | `mixer` | 调音台 | 推子/调音台 |
| `NAV-06` | `avolites-tiger-touch-pro` | Avolites Tiger Touch Pro | 灯光控制台/设备图标 |

按钮顺序已经确认。除非用户明确要求，后续不自动重排，也不因某页面暂未开发而隐藏按钮。

所有 UI、文档和代码统一使用完整名称 `Avolites Tiger Touch Pro`，不使用口语简称。底部按钮空间不足时允许分成两行显示，但不得截断或替换名称。代码和英文路由统一使用 `avolites-tiger-touch-pro`。

## 3. 视觉样式

- 导航栏使用与控制台一致的深黑/深蓝背景
- 6 个按钮等宽横排，填满 B 区主要宽度
- 图标在上、文字在下，整体水平和垂直居中
- 按钮使用方正圆角矩形，不使用胶囊形状
- 当前页面：翡翠绿色图标和文字、绿色描边、克制的外发光
- 非当前页面：灰白色图标和文字，透明或极深色背景
- Hover：边框和文字轻微提亮，不使用位移动画
- Pressed：背景短暂加深，提供明确按压反馈
- Disabled：降低对比度，但仍保留按钮位置和文字
- Focus：显示清晰键盘焦点框，不能只依赖发光

辉光只用于当前页和正常选中重点，不扩散到相邻按钮；告警使用琥珀色或红色。整体保持专业控制台风格，不做霓虹动画。具体颜色见 [暗场颜色令牌](color-tokens.md)。

## 4. 布局与尺寸

- 容器：单行 6 列 CSS Grid，建议 `grid-template-columns: repeat(6, minmax(0, 1fr))`
- 按钮间距：建议 8–12 px
- B 区内边距：建议 12–16 px
- 最小按钮高度：72 px；1920 × 1080 首版建议 88–104 px
- 图标：建议 24–30 px
- 文字：建议 14–16 px，使用中等字重
- 当窗口宽度不足时优先缩小间距和图标，不换行、不变成横向滚动条

## 5. 交互规则

- 单击切换主页面
- 当前页面按钮不可重复触发页面重建
- 页面切换不影响正在播放的歌曲、LED 输出或设备连接
- 切换页面后 `UI-R06 / B` 保持不动，仅更新选中态
- 页面状态可保留；返回音乐或视频管理时恢复之前的搜索、滚动和选中项
- 快捷键暂定 `Ctrl+1` 至 `Ctrl+6` 对应 `NAV-01` 至 `NAV-06`
- 导航按钮不承担播放、黑场等实时动作；这些动作使用独立常驻控制区

## 6. 代码命名

```text
BottomNavigation
  ├─ NAV-01 / home
  ├─ NAV-02 / music
  ├─ NAV-03 / video
  ├─ NAV-04 / lighting
  ├─ NAV-05 / mixer
  └─ NAV-06 / avolites-tiger-touch-pro
```

根节点使用 `data-region-id="UI-R06"`，按钮使用 `data-nav-id="NAV-xx"`，便于自动化测试和后续按编号修改。
