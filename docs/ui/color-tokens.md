# 暗场控制台颜色令牌

状态：已确认主方向

## 1. 设计原则

- 适合酒吧黑暗环境，降低大面积高亮造成的眩光
- 主交互色使用柔和翡翠绿，不使用纯荧光绿 `#00FF00`
- 绿色表示当前选中、正常连接和可执行状态
- 警告、故障和危险操作保留独立颜色语义
- 文字和图标不能只依赖颜色区分状态

## 2. 初始令牌

以下颜色作为 UI 样机起点，最终在真实主控显示器和营业环境中校准亮度：

| 令牌 | 初始颜色 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#080C0A` | 应用主背景 |
| `--color-surface` | `#0E1511` | 面板和按钮背景 |
| `--color-surface-raised` | `#142019` | Hover/抬升面板 |
| `--color-border` | `#26372D` | 普通边框和分隔线 |
| `--color-primary` | `#35D07F` | 当前页、主要操作、正常连接 |
| `--color-primary-soft` | `#1F8F57` | 低强度选中背景和描边 |
| `--color-primary-text` | `#8AF0B8` | 深色背景上的绿色强调文字 |
| `--color-text` | `#E5ECE8` | 主要文字 |
| `--color-text-muted` | `#8E9D95` | 次要文字和未选中图标 |
| `--color-warning` | `#E4A93A` | 警告、缺少绑定、即将切换 |
| `--color-error` | `#E05252` | 故障、断线、执行失败 |
| `--color-danger` | `#F04444` | 紧急黑场等危险操作 |
| `--color-info` | `#5BA7D9` | 中性信息和调试状态 |

## 3. 暗场使用规则

- 大面积区域只使用背景和面板色，不铺满高亮绿色
- 绿色辉光仅用于当前导航、`ON AIR`、焦点和关键连接状态
- 辉光半径和透明度保持克制，不能影响文字边缘清晰度
- 正常正文不使用绿色，避免长时间阅读疲劳
- `ON AIR` 同时显示文字/图标/边框，不只显示绿色
- 故障不能显示为绿色；使用红色加错误图标和文字
- 紧急黑场按钮保持危险红色，避免误认为普通绿色操作
- 提供 UI 亮度档位，建议包含“暗场、标准、明亮”三档；只调整界面强度，不改变状态语义
