# `UI-R05 / R` 视频与灯光快捷区

状态：已确认

版本：1.0

## 1. 区域划分

首页 `UI-R05 / R` 上下均分：

```text
┌────────────────────────────┐
│ R1：视频快速选择           │  50%
│ 静态缩略图 + 时长          │
│ 滚动选择，单击立即播放     │
├────────────────────────────┤
│ R2：灯光快捷控制           │  50%
│ 灯光预设 + 常用灯光        │
│ Tiger Touch 简易控制       │
└────────────────────────────┘
```

- `R1` 和 `R2` 初始各占 R 区高度 50%
- 分隔线位置默认固定，后续如允许拖动也必须提供“一键恢复 50/50”
- 两个子区域分别滚动，互不推动对方离开可视区域

## 2. `R1` 视频快速选择

### 内容

每个视频卡片只显示：

- 静态预览图片
- 右下角或右上角的 `mm:ss` / `hh:mm:ss` 时长
- 当前播放所需的绿色边框/播放图标状态

首页不显示视频名称、文字介绍、分类说明、上传、新建、编辑或删除按钮。完整信息与管理功能只在“视频管理”页面提供。

### 布局

- 采用紧凑缩略图网格，R 区常规宽度优先显示 2 列
- 缩略图使用统一卡片比例和 `object-fit: cover`
- 视频较多时区域内部纵向滚动
- 滚动条保持低对比度，Hover/拖动时再提亮
- 当前播放视频始终显示绿色描边和播放标识
- 缩略图加载失败时显示统一占位图，但仍保留时长

### 操作

- 单击缩略图立即播放该视频，不弹出二次确认
- 点击新视频时，根据设置执行硬切或短视频淡化；默认使用短淡化
- 当前歌曲音频默认继续播放，快速选择的视频默认只替换 LED 画面
- 视频文件自带音频默认静音，避免与歌曲声音重叠；只有在视频管理中明确允许才可输出其音频
- 视频较短时按素材配置决定单次播放或循环
- 视频播放结束后按配置返回歌曲画面或默认背景
- 区域标题处提供紧凑的“返回歌曲画面/停止临时视频”控制

### 状态

- `PLAYING`：绿色边框和播放图标
- `LOADING`：轻量加载指示，临时禁止重复点击同一卡片
- `ERROR`：红色错误角标，不使用弹窗遮挡主控制台
- 已加载但未播放：正常缩略图，不使用 READY 高亮以免与 Deck 状态混淆

## 3. `R2` 灯光快捷控制

“老虎机”在本项目中指 Avolites Tiger Touch Pro 灯光控制台，不指博彩老虎机。R2 是其简化快捷操作区，完整配置和管理在“灯光管理”及底部“老虎机”页面完成。

### 内容分组

- 灯光预设：已经在 Tiger Touch 中编排并映射的 Cue/Playback
- 常用灯光：营业中最常用的颜色、亮度、位置或组合快捷项
- 安全操作：停止/释放当前临时灯光，返回歌曲默认灯光

### 灯光卡片

每个快捷卡片至少包含：

- 简短预设名称或编号
- 颜色/效果缩略表示
- 连接与可用状态
- 当前激活状态

灯光不能只用颜色区分，必须同时显示名称/编号和状态图标。

### 操作

- 单击预设立即向 Tiger Touch 触发已映射的 Cue/Playback
- 当前激活项使用绿色边框、半透明背景和 `ACTIVE` 标识
- 正在发送显示 `SENDING`，收到确认后变为 `ACTIVE`
- 发送失败显示红色状态并允许重试，不影响当前音视频播放
- 常用灯光可固定到 R2，排序在“灯光管理”页面维护
- 首页不提供灯具 Patch、DMX 地址、Cue 编程、删除或重命名
- 歌曲自动灯光仍由 C2/播放编排触发；R2 的人工操作作为临时覆盖，并清楚显示覆盖状态

## 4. 区域与页面边界

| 首页 R 区 | 管理页面 |
| --- | --- |
| 快速选择并播放视频 | 导入、生成缩略图、编辑、分类和删除视频 |
| 触发已配置灯光预设 | 建立 Tiger Touch 映射、编辑常用项和测试连接 |
| 查看当前快捷状态 | 查看完整设备参数、日志和诊断 |

## 5. 编号与代码命名

| 子区域 | 固定编号 | React 组件建议名 | DOM 标识 |
| --- | --- | --- | --- |
| R 上部视频 | `UI-R05-A` | `VideoQuickSelect` | `region-right-video` |
| R 下部灯光 | `UI-R05-B` | `LightingQuickControl` | `region-right-lighting` |

根区域仍使用 `data-region-id="UI-R05"`；子区域分别使用 `data-subregion-id="UI-R05-A/B"`。
