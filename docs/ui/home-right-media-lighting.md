# `UI-R05 / R` 视频与灯光快捷区

状态：已确认

版本：1.20

## 1. 区域划分

首页 `UI-R05 / R` 上下均分：

```text
┌────────────────────────────┐
│ R1：视频快速选择           │  占剩余高度
│ 静态缩略图 + 时长          │
│ 滚动选择，单击立即播放     │
├────────────────────────────┤
│ R2：灯光快捷控制           │  紧凑内容高度
│ 灯光预设 + 常用灯光        │
│ Avolites Tiger Touch Pro   │
│ 简化快捷控制               │
└────────────────────────────┘
```

- `R2` 只包含一行标题、两行正方形预设和一行快捷操作，按内容高度紧凑排列；不再与 R1 强制均分高度
- `R1` 占用 R 区剩余高度，视频网格在其内部纵向滚动

## 2. `R1` 视频快速选择

### 内容

每个视频卡片只显示：

- 静态预览图片
- 视频缩略图网格必须从顶部紧凑排列，隐式行使用内容高度，纵向行距与横向间距保持完全一致；禁止把行高拉伸来填满 R1 剩余高度
- 右下角或右上角的 `mm:ss` / `hh:mm:ss` 时长
- 当前播放所需的绿色边框/播放图标状态

首页不显示视频名称、文字介绍、分类说明、上传、新建、编辑或删除按钮。完整信息与管理功能只在“视频管理”页面提供。

### 布局

- R1 标题下方固定一行三等分素材类型按钮：`视频`、`图片`、`文字`；默认选中`视频`
- R1 标题栏右侧提供独立的“视频声音 / 已静音”切换，只控制视频文件自身音轨；默认静音，避免视频音轨意外与 L 区音乐同时送到大厅
- 关闭视频声音时视频继续正常出画面；L 区 Deck 1、Deck 2、Crossfader 与调音台状态不得被该按钮改变
- 打开视频声音后，视频音轨允许与 C2 的 Deck 1、Deck 2 同时输出并混音，不执行互斥切换、自动暂停、自动压低或自动移动 Crossfader
- 操作员通过两个 Deck 各自的播放/暂停按钮手动关闭音乐；Crossfader 始终只控制 Deck 1 与 Deck 2 的相对音量，不控制视频音轨
- 选择“视频”或“图片”时，在类型按钮下方显示 6 个等分分类单选按钮；视频默认分类为`全部 / 舞台 / 激光 / 氛围 / 节日 / 宣传`，图片默认分类为`全部 / 背景 / 海报 / 欢迎 / 生日 / 活动`；选择“文字”时不显示分类行
- 分类按钮同一时刻只允许选择一项；切换素材类型时自动回到“全部”
- 分类文字字号与 L 区“周一至周日”按钮保持一致，保证暗场可读性
- 三个类型按钮采用与 L 区曲库切换相同的直线分割和底部绿色选中线，不使用独立圆角卡片
- 点击类型按钮只切换 R1 的素材类别，不改变当前大屏输出；实际播放/上屏仍需点击具体素材
- 采用紧凑缩略图网格，每行固定显示 3 个缩略图；列宽随 R 区可用宽度均分
- 缩略图使用统一卡片比例和 `object-fit: cover`
- 缩略图的列间距与行间距必须相同，默认使用紧凑的 `5px`；不额外拉大行距
- 视频较多时区域内部仅纵向滚动；禁止出现横向滚动条
- 滚动条保持低对比度，Hover/拖动时再提亮
- 当前播放视频始终显示绿色描边和播放标识
- 缩略图加载失败时显示统一占位图，但仍保留时长
- 图片或文字类别暂时没有素材时显示明确的空状态，不显示视频缩略图以免操作员误判
- 图片列表使用独立的 `8:9` 缩略图比例，每行 4 个；不得沿用视频的 `16:9` 缩略图比例
- 图片列表第一项固定为黑屏，始终置顶，不参与目录扫描结果排序，不可移动、不可删除
- 其余图片由桌面端扫描应用图片库目录生成，支持 `PNG / JPG / JPEG / WebP / BMP / GIF`；文件名用于稳定排序，分类子目录对应图片分类
- 视频、图片和文字统一采用安全的 `Preview → Take` 流程：鼠标悬停素材时 C1 临时预览，现场输出保持不变；单击素材后锁定预览，再点击 C1 的“上屏”才切换实际输出
- 双屏预览开启期间，PVW 控制条长期保留“重置 / 上屏”。“重置”取代原“取消”：点击后将 PVW 的媒体、图文元素及变换参数恢复成当前 PGM，现场输出保持不变
- 预览视频不得提前启动或切换视频音轨；视频声音开关只作用于已经确认上屏的视频
- 视频和图片默认只显示素材本身，不自动叠加 KING CLUB、歌曲名、歌手名或其他系统演示文字；所有文字与 Logo 必须由“文字”模板或图文编辑器明确添加

### 文字与图文叠加模板

- “文字”页第一行固定显示 4 个预设模板按钮；模板可以组合文字、可改色 SVG/Logo 和图片元素
- 选择模板后自动打开 C1 的 PGM/PVW 双屏预览；模板只进入 PVW，不得直接改变 PGM 当前画面
- 模板属于叠加层，当前视频或图片继续作为底图，不得被替换成纯色文字整屏
- 在 PVW 中单击文字、Logo/SVG 或图片即可选择该元素；选中项显示蓝色高对比编辑框
- 元素选中后显示完整矩形边框以及四角、四边共 8 个控制点；按住元素主体直接拖动位置。四个角点保持当前宽高比例进行等比缩放，左右中点只改变宽度，上下中点只改变高度，可用于文字、SVG/Logo 和图片的拉伸变形
- 点击 PVW 画面空白区域立即取消当前选择和控制边框；点击另一个元素时只保留新元素的控制边框
- 图文编辑支持桌面快捷键：`Ctrl+Z` 撤销上一次编辑，`Ctrl+C` 复制当前元素，`Ctrl+V` 粘贴并错开副本，`Delete` 或 `Backspace` 删除当前元素
- 快捷键只在 PVW 图文编辑状态下生效；焦点位于文字输入框时保留 Windows 原生文字编辑快捷键，防止与元素级操作冲突
- 双击 PVW 中的文字元素直接进入画布内文字编辑，显示输入光标并临时隐藏缩放控制点；`Enter` 提交本次修改，`Esc` 放弃本次修改。退出文字编辑后恢复选框和 8 个控制点
- 画布内文字编辑期间禁止触发元素拖动，文字内容仍保留原位置、比例、颜色和排版效果；SVG/Logo 与图片不进入文字输入状态
- 直接操作期间必须实时更新 PVW；松开鼠标后保留新位置与比例。不得在元素旁显示浮动属性框；选中元素后统一在 C1 预览区底部显示一行紧凑工具栏
- 底部工具栏提供元素颜色、左/水平中/右对齐、上/垂直中/下对齐、字体、字号、加粗、斜体、阴影开关、阴影颜色、飞入和淡出；不显示删除按钮，避免现场误点
- 文字和 SVG 的阴影可分别打开或关闭；阴影关闭后颜色选择器禁用。有些文字可以完全不带阴影
- PNG 位图始终不应用文字阴影、外发光或矩形盒阴影；选择 PNG 时阴影控件不作用于该元素
- 同一条工具栏只提供一个“PNG/SVG”图形上传按钮，由文件扩展名自动识别 PNG 或 SVG；不显示独立的“更新”按钮
- 上传后的 PNG 保留原始彩色与 Alpha 透明通道，透明像素必须直接显示其下方的视频或图片；PNG 容器不得使用元素颜色填充，也不使用黑白或亮度混合效果。SVG 作为可改色矢量元素处理。两者均立即进入当前 PVW，并支持拖动与缩放
- `Ctrl` 或 `Shift` 配合点击允许同时选择多个文字、SVG/Logo 或图片元素；工具栏显示已选数量。颜色、阴影、对齐和动画可批量应用，字体、字号、加粗与斜体只应用于其中的文字元素；删除继续使用键盘 `Delete / Backspace`
- 多元素对齐以当前选择集合为基准；单元素对齐则以整个 PVW 画布为基准。工具栏必须保持单行完整显示，不产生横向溢出
- 六个对齐命令使用设计软件通用的纯图形图标，顺序为左对齐、水平居中、右对齐、顶部对齐、垂直居中、底部对齐；不在按钮中显示单字简称
- 字体家族不使用固定写死列表；Tauri/Rust 桌面端启动时读取 Windows 已安装字体，并在工具栏中提供可搜索下拉列表。网页原型环境仅使用明确的回退字体
- 字体控件依次显示字体家族、字重和字号：字重至少提供 Light、Regular、Medium、SemiBold、Bold、Heavy，字号使用带上下步进的数值输入并显示 `pt`
- 图文编辑工具栏在双屏预览期间长期保留；没有选中元素时格式操作禁用，但上传和工作台仍可用。点击“上屏”立即提交当前 PVW，随后 PVW 保留为可继续编辑的副本，不关闭编辑条；点击“重置”则放弃 PVW 未上屏修改并恢复为 PGM
- 第二行固定提供 4 个暂存位；暂存卡片与上方模板卡片使用相同列宽和 `8:9` 比例，并直接缩略显示已保存文字、SVG/Logo、图片的位置和样式，保证操作员能够目视预览；已有暂存位在没有待编辑图文时可直接调回 PVW
- 暂存位只允许从空位建立：左键点击空暂存位后，PVW 进入“新图文画面”，操作员可从模板区选择模板并编辑
- C1 图文编辑始终只保留一条工具栏，不能因打开空暂存位或选择模板而出现第二条；“保存暂存 N”固定在同一条编辑栏最右侧
- 有内容的暂存位左键调取到 PVW 并绑定对应暂存位；后续修改必须点击同一条编辑栏右侧的保存按钮，覆盖回该暂存位。右键点击有内容的暂存位才弹出“清空暂存”确认，确认后恢复为空位
- 4 个预设模板按钮只显示模板画面预览，不在卡片底部重复显示绿色模板分类小字
- 暂存内容保存元素类型、内容、位置、比例和颜色，并持久化在主控电脑本机，供操作员提前准备生日、庆祝和欢迎信息
- 暂存位只保存图文叠加内容，不固化当时的底图；调取时叠加到当前正在使用的视频或图片之上

### 操作

- 单击缩略图立即播放该视频，不弹出二次确认
- 点击新视频时，根据设置执行硬切或短视频淡化；默认使用短淡化
- 当前歌曲音频默认继续播放，快速选择的视频默认只替换 LED 画面
- 视频文件自带音频默认静音，避免与歌曲声音重叠；只有在视频管理中明确允许才可输出其音频
- 视频较短时按素材配置决定单次播放或循环
- 视频播放结束后按配置返回歌曲画面或默认背景
- 区域标题处提供紧凑的“返回歌曲画面/停止临时视频”控制

### 状态

- `PLAYING`：绿色边框和播放图标
- `LOADING`：轻量加载指示，临时禁止重复点击同一卡片
- `ERROR`：红色错误角标，不使用弹窗遮挡主控制台
- 已加载但未播放：正常缩略图，不使用 READY 高亮以免与 Deck 状态混淆

## 3. `R2` 灯光快捷控制

R2 是 Avolites Tiger Touch Pro 的简化快捷操作区，完整配置和管理在“灯光管理”及底部“Avolites Tiger Touch Pro”页面完成。所有界面、文档和代码统一使用完整设备名称，不使用口语简称。

### 内容分组

- 灯光预设：已经在 Tiger Touch 中编排并映射的 Cue/Playback
- 常用灯光：营业中最常用的颜色、亮度、位置或组合快捷项
- 安全操作：停止/释放当前临时灯光，返回歌曲默认灯光

### 灯光卡片

- 标题右侧使用“灯光开启 / 灯光关闭”按钮取代原 `控台连接正常` 状态文字；点击开启状态会关闭全部灯光，点击关闭状态会重新开启灯光，并恢复当前预设或自动灯光；关闭时预设区与快捷操作区降亮显示
- 首页 R2 显示固定 10 个预设按钮，编号 `0` 至 `9`，每行 5 个、共两行；列宽均分，行距与列距固定同为 `4px`，两行从顶部紧凑排列，剩余空间只保留在第二行下方
- 预设按钮必须为正方形，编号在按钮正中；使用紧凑内边距且不产生横向滚动
- 每个编号有三种状态：未配置仅显示弱化编号且不可触发；已配置显示编号、用户自定义名称和时长；当前激活项使用完整绿色高亮边框及低透明度背景
- 已配置预设的名称显示在编号下方；右下角显示该 Cue/Playback 的时长；左下角是小型循环/单次切换按钮，循环使用循环图标，单次使用数字 `1`
- 预设网格下方的快捷操作行保留；第一个按钮为“自动”而非“闪烁”，其后依次是`光束`、`加特林`、`摇头染色`和`LED`，共 5 个等分按钮
- `光束`、`加特林`、`摇头染色`、`LED`是固定四色调色板，不使用选中状态；按钮文字前显示当前颜色的小圆形灯
- 双击任一调色板按钮在该按钮正上方打开软件内置的大型调色板；左侧饱和度/明度色块和中间色相条均可用鼠标直接拖动，右侧同步显示 RGB 数值与颜色预览；调节结果立即反映到对应按钮的纯色背景，小圆灯固定白色
- 调色板按钮根据背景亮度自动保证文字反差：浅色背景显示黑字，深色背景显示白字
- 底部行文字字号与预设按钮中的自定义名称一致；四个设备按钮分别使用绿色、橙色、紫色、蓝色的纯色背景和白色文字

每个预设快捷卡片至少包含：

- 固定编号 `0` 至 `9`
- 连接与可用状态
- 当前激活状态
- 已配置时的自定义名称、时长和循环/单次状态

首页首版用编号区分预设；完整名称、颜色、效果及 Tiger Touch 映射在“灯光管理”页面维护。

### 操作

- 单击预设立即向 Tiger Touch 触发已映射的 Cue/Playback；重复点击当前激活预设保持其选中状态，避免误触取消
- 点击“自动”会取消当前预设选择，并恢复自动灯光编排；自动状态明确高亮，但 0–9 预设均不选中
- 当前激活项使用绿色边框、半透明背景和 `ACTIVE` 标识
- 正在发送显示 `SENDING`，收到确认后变为 `ACTIVE`
- 发送失败显示红色状态并允许重试，不影响当前音视频播放
- 常用灯光可固定到 R2，排序在“灯光管理”页面维护
- 首页不提供灯具 Patch、DMX 地址、Cue 编程、删除或重命名
- 歌曲自动灯光仍由 C2/播放编排触发；R2 的人工操作作为临时覆盖，并清楚显示覆盖状态

## 4. 区域与页面边界

| 首页 R 区 | 管理页面 |
| --- | --- |
| 快速选择并播放视频 | 导入、生成缩略图、编辑、分类和删除视频 |
| 触发已配置灯光预设 | 建立 Tiger Touch 映射、编辑常用项和测试连接 |
| 查看当前快捷状态 | 查看完整设备参数、日志和诊断 |

## 5. 编号与代码命名

| 子区域 | 固定编号 | React 组件建议名 | DOM 标识 |
| --- | --- | --- | --- |
| R 上部视频 | `UI-R05-A` | `VideoQuickSelect` | `region-right-video` |
| R 下部灯光 | `UI-R05-B` | `LightingQuickControl` | `region-right-lighting` |

根区域仍使用 `data-region-id="UI-R05"`；子区域分别使用 `data-subregion-id="UI-R05-A/B"`。
