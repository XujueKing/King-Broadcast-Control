# UI 与交互设计

状态：待需求确认  
版本：0.1

## UI 目标

- 暗色、低干扰，适合酒吧现场环境
- 高频操作一步可达
- 播放状态、设备状态和异常清晰可辨
- 关键操作防误触，但不拖慢现场操作
- 重要信息不只依赖颜色表达

## 候选信息架构

- 总控台
- 素材库
- 播放列表 / 节目单
- 场景
- 设备状态
- 日志与告警
- 系统设置

以上导航项将在操作流程确认后增删。

## 控制台待讨论

- 主预览区与待播预览区是否需要双画面
- 播放控制、切换方式和转场参数
- 多屏/分区选择方式
- 场景快捷键与实体 MIDI/键盘快捷键
- 紧急停止/黑场的位置、颜色和确认方式
- 离线、延迟、指令失败、状态不一致的反馈方式
- 触控屏目标尺寸、分辨率和最小点击区域

## 设计交付顺序

1. 核心任务流
2. 低保真线框图
3. 视觉方向与设计令牌
4. 高保真控制界面
5. 可交互原型与现场可用性验证
6. 确认后进入前端实现
