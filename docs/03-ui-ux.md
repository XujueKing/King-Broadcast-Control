# UI 与交互设计

状态：控制台信息架构草案

版本：0.2

固定区域编号见 [UI 控制台区域编号](ui/console-region-map.md)。后续讨论和实现统一使用 `UI-R01` 至 `UI-R06`，并兼容图片代号 `T/L/C1/C2/R/B`。

正式 Logo 和使用规则见 [品牌资产](ui/brand-assets.md)。

`UI-R06 / B` 的横向主导航见 [底部主导航](ui/bottom-navigation.md)。

全控制台暗场配色见 [颜色令牌](ui/color-tokens.md)。

## UI 目标

- 暗色、低干扰，适合酒吧现场环境
- 采用朴素的专业控制台风格，不追求花哨动画、玻璃效果或装饰性视觉
- 高频操作一步可达
- 播放状态、设备状态和异常清晰可辨
- 关键操作防误触，但不拖慢现场操作
- 重要信息不只依赖颜色表达
- 信息密度优先，但通过稳定分区、字号和间距保持清晰

## 视觉方向

- 深灰/黑色背景，减少暗场环境眩光
- 主交互和正常状态使用柔和翡翠绿，警告使用琥珀色，故障和危险使用红色
- 方正面板、清晰边框、大号操作按钮和紧凑表格
- 底部主导航采用适合暗场的绿色选中态，按钮为单行横排
- 不使用持续动画；仅在加载、执行中和故障告警时使用必要动效
- 播放、暂停、下一首、原伴唱、黑场等按钮依赖文字加图标，不只依赖图标猜测
- 控制台优先适配 1920 × 1080；后续根据实际操作显示器补充分辨率

## 候选信息架构

- 总控台
- 素材库
- 播放列表 / 节目单
- 场景
- 设备状态
- 日志与告警
- 系统设置

以上导航项将在操作流程确认后增删。

## 首版控制台布局草案

建议首屏保持四个持续可见区域：

- 左侧：星期节目、歌单和播放顺序
- 中央：主屏实时预览、当前歌曲和播放进度
- 右侧：歌曲绑定的视频、灯光预设及设备状态
- 底部：原声/伴唱、上一首、播放/暂停、下一首、播放模式、黑场等高频控制

视频库、灯光预设库和文字投放使用可切换工作区，但当前播放状态和紧急黑场始终可见。

`UI-R03 / C1` 已固定为 LED 主屏实时预览。预览采用现场 T 形屏的 8:9 外框比例，不以普通 16:9 矩形代替，也不随容器拉伸。

### 歌单管理界面

- 顶部固定展示星期一至星期日 7 个常规歌单入口
- 独立展示活动、节日、主题夜等特别歌单，可按标签和日期筛选
- 编辑区左侧为歌曲库，右侧为歌单条目，支持搜索后拖入和批量选择
- 歌单头部持续显示歌曲数、累计时长、是否达到 8 小时、缺失资源数和发布状态
- 正在营业使用的版本明确标记，编辑草稿不立即影响当前播放
- “发布”“应用到当前播放”“替换当前队列”必须是三个含义清晰的动作
- 特别歌单启动时，让操作员选择“替换常规歌单”或“插入当前队列”

### 歌曲条目编辑器

选中歌单中的歌曲后，右侧打开编辑面板：

- 基本信息：歌曲名、歌手、分类、备注
- 声音：选择 MP4 内置音轨或独立 MP3/FLAC/WAV
- 原伴唱：选择左右声道、音轨或独立文件，并设置默认模式
- 画面：原 MP4、自有视频、静态图或默认背景
- 视频行为：循环、从头播放、起始偏移、歌曲结束时停止
- 灯光：选择默认预设及触发时机
- 故障回退：原 MP4 视频或默认背景

歌单列表每行用简洁图标显示当前组合，例如“MP4 原片”“MP4 声音 + 自有视频”“MP3 + 自有视频”，并提示缺失素材，避免必须打开编辑器才能发现配置问题。

### 常驻播放控制条

控制条在所有主界面页面持续可见，按操作频率分组：

- 主控制：上一首、播放/暂停、停止、下一首
- 进度：可拖动进度条、已播放时间、剩余时间
- 声音：原声/伴唱、静音、音量
- 画面：原 MP4、自有视频、临时选视频、默认背景
- 模式：顺序、单曲循环、列表循环、随机
- 安全：待机画面、紧急黑场

### 双 Deck 控制区

主预览附近设置简化的 Deck A / Deck B 区域：

- 每个 Deck 显示歌曲名、歌手、封面/视频缩略图、播放位置、剩余时间、原伴唱和加载状态
- 当前主 Deck 使用明确边框和 `ON AIR` 标识，不能只靠颜色
- 待播 Deck 显示 `LOADING`、`READY` 或具体错误
- 两 Deck 中间放置水平 Crossfader，左右端清楚标记 A/B
- 提供“自动过渡”按钮和 3 秒、5 秒、自定义时长选择
- 提供“立即切换”按钮，供现场快速处理
- 自动模式下显示过渡倒计时，并允许操作员取消

界面借鉴 DJ 台的双 Deck 心智模型，但不模拟转盘、波形特效和大量旋钮，保持播控台简洁。

当前歌曲名、歌手、当前音轨、当前画面来源、灯光预设和下一首始终显示在控制条附近。

按钮交互：

- 播放/暂停、原伴唱和画面切换为单击操作
- 下一首可单击执行，设置页可启用双击防误触
- 停止需要短确认；紧急黑场无需确认，一步生效
- 设备正在执行时显示进度态，短时间内禁止重复提交相同指令
- 快捷键支持空格播放/暂停及可配置的上一首、下一首、原伴唱和黑场按键

### 状态层级

- 正常：当前内容、剩余时间、播放模式清晰可见
- 注意：设备未连接、绑定缺失，但仍可继续音视频播放
- 故障：输出进程异常、主屏丢失或关键播放失败
- 紧急：黑场/清屏已启用，需要明确显示且一键可恢复到待机画面

### 防误操作

- 播放/暂停和下一首不做弹窗确认，但按钮目标足够大
- 清空歌单、停止全部输出、修改设备配置需要确认
- 紧急黑场应一步触发；解除黑场需要明确动作
- 随机播放开启时展示下一首候选，避免现场完全不可预期

## 控制台待讨论

- 主预览区与待播预览区是否需要双画面
- 播放控制、切换方式和转场参数
- 多屏/分区选择方式
- 场景快捷键与实体 MIDI/键盘快捷键
- 紧急停止/黑场的位置、颜色和确认方式
- 离线、延迟、指令失败、状态不一致的反馈方式
- 触控屏目标尺寸、分辨率和最小点击区域
- 原声/伴唱开关的真实素材结构与切换延迟
- 星期节目是标签、日历还是时间轴形式
- 文字覆盖视频时的安全区与默认样式

## 设计交付顺序

1. 核心任务流
2. 低保真线框图
3. 视觉方向与设计令牌
4. 高保真控制界面
5. 可交互原型与现场可用性验证
6. 确认后进入前端实现
