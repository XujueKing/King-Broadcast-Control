# KING CLUB 现场硬件拓扑基线

状态：现场照片与口述已确认，端口、通道、IP 与协议待逐项勘验  
更新日期：2026-08-25

本文是 KING CLUB 播控项目的现场设备与信号链基线。实现、部署和故障排查不得仅凭设备名称推测接线；未拍照或未读取配置的内容必须继续标记为待确认。

## 1. 系统总览

```text
                            KING CLUB
                                │
                         中控电脑（未来）
                                │
             ┌──────────────────┼──────────────────┐
             │                  │                  │
           AUDIO              LIGHT              VIDEO
             │                  │                  │
  Shure SLX4 无线接收器  Avolites Tiger Touch Pro  mpv
             │                  │                  │
   Allen & Heath Qu-16        DMX512        Windows 视频输出
             │                  │                  │
   DP448 Audio Management   DSP8 Splitter ×3   LED 视频系统
             │                  │                  │
          多台功放             全场灯具          全场屏幕
             │
          全场音箱
```

`DSP8 Splitter ×3` 是 DMX 灯光信号分配设备，只属于 LIGHT 链路，不参与音频分配、音频 DSP、人声增强、功放或音箱管理。

## 2. 音频链

现场主链：

```text
无线话筒发射器
       │ RF
       ▼
Shure SLX4 无线麦克风接收器
       │ 模拟音频（接口待确认）
       ▼
Allen & Heath Qu-16 输入通道
       │ 主混音模拟输出（端口待确认）
       ▼
DP448 Audio Management System（面板确认 4 输入 / 8 输出）
       │ 输出分配与系统处理（配置待导出）
       ▼
多台功放
       ▼
全场音箱
```

实时人声增强的规划插入点在 Qu-16 USB 音频回路内，而不是 DP448 后方：

```text
SLX4 → Qu-16 → USB Input → 中控电脑 Vocal Engine
                                  │
                     USB Return ←─┘
                          │
                        Qu-16 → DP448 → 功放 → 音箱
```

设计约束：

- SLX4 不直接连接中控电脑；Vocal Engine 从 Qu-16 USB 输入取得指定麦克风通道。
- Vocal Engine 故障、进程退出或 USB 断开时，Qu-16 必须能回到未经电脑处理的安全人声路径。
- DP448 位于总混音下游，继续负责当前现场系统处理；不得用它替代 Qu-16 的多路混音或电脑低延迟 USB 回路。
- 现场正面照片已确认面板型号为 `DP448 Audio Management System`，并可见 A-D 四路输入选择和 1-8 八路输出选择；品牌、真伪、背板接口和控制协议仍待背面铭牌与配置软件确认。

## 3. 灯光链

```text
中控电脑
   │ 仅触发已批准的 Cue/Playback（协议待验证）
   ▼
Avolites Tiger Touch Pro
   │ DMX512
   ▼
DSP8 Splitter ×3
   │ 多路 DMX 分配
   ▼
全场灯具
```

设计约束：

- Tiger Touch Pro 是灯光节目和 DMX 输出的权威设备。
- KING 软件只触发已编排的 Cue/Playback，不让通用 UI 绕过灯光台直接接管全场 DMX。
- DSP8 只做灯光 DMX 分配；它不属于 AUDIO 链，软件不得把它建模成音频 splitter 或声场 DSP。

## 4. 视频链

```text
中控电脑 mpv
      │ Windows 显示输出
      ▼
现有 LED 视频处理/发送系统
      ▼
主 LED 屏及后续扩展屏
```

当前软件把 LED 系统视为 Windows 显示器，不直接配置模组、接收卡或发送卡。

显示输出遵守固定预设：逻辑节目画布保持 `2048×2304`（8:9），物理 LED 墙保持 `5120×5760 mm`（8:9），并保留昨晚确认的 16:9 视频处理器传输补偿。软件启动时主动请求 Windows 扩展桌面；发现主控屏以外的第二屏后，直接把 PGM 窗口恢复到该屏。软件只切换复制/扩展状态，不修改各显示器的分辨率、缩放、刷新率或宽高比。接普通显示器进行异地预览时，传输画面按固定 16:9 等比例缩放，剩余区域显示黑边，不拉伸、不重新计算 LED 预设。

## 7. 营业声场模式方案

电脑和 Pioneer XDJ-XZ 都向 Qu-16 提供完整的立体声 L/R，不在播放器内拆分高音、中音、低音和超低音。Qu-16 负责人声、音乐源、节目混音和受限的操作员音色调节；DP448 负责音箱分组、系统分频、延时、系统 EQ、限幅和最终保护。

软件提供 `SUB / LOW / MID / HIGH` 四段操作员音色控制，但它们不能覆盖 DP448 的安全层。第一阶段只允许在受控范围内微调，不允许直接改写分频、相位或扬声器保护参数。

预设三种营业模式：

| 模式 | 用途 | 低频策略 |
|---|---|---|
| DAY | 白天及正常营业 | 保留经现场工程师确认的完整系统效果 |
| NIGHT | 夜间营业 | 强化低频保护，目标是减少 50 Hz 以下的结构传播，同时尽量保留约 50-90 Hz 的节奏冲击 |
| DEEP NIGHT | 深夜及居民保护 | 在 NIGHT 基础上进一步降低 SUB 最大电平和限幅上限 |

上述频率、斜率、PEQ、Delay 和 Limiter 数值都不是当前已批准参数。必须先备份 DP448 当前工程，确认 8 路输出到功放/音箱的映射，并在一楼客区和三楼居民侧同步测量后才能写入。模式切换第一阶段必须由操作员确认，任何工作人员的音色调节都不能绕过 NIGHT/DEEP NIGHT 安全层。

### Tiger Touch / DSP8 / 灯具

- Tiger Touch Pro 序列号、Titan 版本、show 文件和控制网络；
- 三台 DSP8 的厂商、型号、输入/输出端口和 DMX Universe 分配；
- 每路 DSP8 输出对应的灯具链、地址范围及终端电阻情况。

任何自动控制或驱动接入，都必须以配置备份和现场回读为依据；未完成真机验证时只能标记为协议/mock 阶段。
