# KINGCLUB Qu-16 主输出恢复基准

基准标识：`kingclub-2026-08-26-st3-lr`

该基准只固定 2026-08-26 收工记录和 Qu-16 协议能够共同证明的电脑主播放关键链路：

- 电脑 USB 音乐源为 `ST3`；
- `ST3` 与 `LR Master` 推子恢复到 Qu 协议原始值 `0x62`（实体 `0 dB`）；
- `ST3` 与 `LR Master` 的 Mute 关闭；
- `ST3` Assign 到 `LR`；
- `ST3` PAFL 关闭。

软件不会在启动、重连或调音台重启后自动写入该基准。操作员必须在调音台工作区主动点击“恢复 8/26 主输出”，确认功放/DP448 已降低后才发送；发送完成后必须等待 Qu-16 权威回读全部一致，界面才报告成功。

该按钮不会修改 `CH11/CH12` 备用模拟链路、任何麦克风通道、Preamp/48V、Gate/PEQ/Comp、DCA、Mute Group、Mix Send 或 DP448。仓库没有 8 月 26 日整台 Qu Scene 的二进制备份，因此不得把这组关键链路恢复描述成整台调音台全部参数或 Scene 的完整还原。

CUE 只改变 `ST3 → LR Assign` 与 `ST3 PAFL`，不再触碰 `ST3` 或 `LR Master` 推子。这样即使 CUE 中途切换或应用异常退出，也不会再把主输出推子留在 `-∞`。
