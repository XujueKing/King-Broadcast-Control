# 主唱局域网接口交付验证 · 2026-09-09

本轮只交付中控接口与平板客户端协议，平板程序在后续独立项目开发。接口与操作含义见 [SINGER-LAN-API.md](./SINGER-LAN-API.md)。

## 实现

- 设置页增加主唱接口启停、端口、演唱 Deck、连接地址、密钥显示/更换；默认关闭，开启后可随程序恢复。
- Axum 提供认证后的曲库分页搜索、同步歌词、真实播放状态、主唱操作和执行回执；不暴露媒体路径、任意文件或通用 Tauri 调用。
- 选歌/切歌明确指定目标歌曲，接管背景音乐并暂停两路 Deck，再准备单曲演唱；播放、暂停、原唱/伴唱、重唱复用桌面控制流程。
- 同 ID 请求复用回执；旧会话/旧修订/过期指令拒绝执行；未完成操作限一条，播放器失联不伪报成功。
- 移除阻塞离线启动的 Google Fonts 样式导入，使用本机字体；连接设置区改为按内容高度滚动，避免挤压原有硬件设置。
