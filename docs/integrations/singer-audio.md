# 主唱全场演唱调音

主唱 APK 演唱页点击「调音」。中控「设置 → 主唱平板连接」增加相同控制及「主唱调音权限」。两端共享中控状态，不把现场音频传到手机。

- 伴奏音量：现有电脑音乐输出，包含当前原唱/伴唱模式；不会改变麦克风或 Qu-16 LR 总推子。
- 麦克风音量：管理员明确绑定 CH1、CH2 或 CH6 中的一路，控制该通道推子。
- 混响大小：绑定的麦克风到 FX1 或 FX2 的发送量。必须先现场确认这个 FX 配置为混响并接入主扩；软件不猜效果算法，不改变 FX 返回总推子。
- 清唱：伴奏降到 0，播放/暂停状态和歌词时钟保持，麦克风与效果不变。退出时恢复进入前音量，服从最新音量上限。换歌保留清唱状态；本机手动修改音乐总音量会退出清唱。重启不会自动恢复清唱意图或开始播放。

## 配置

管理员按现场表计确认歌手通道，选择已配置的混响 FX 总线，保存各项调节上限。默认麦克风和效果总线均未绑定，保存配置不会写硬件。麦克风/混响上限不得超过 UI 77（MIDI 98，约 0 dB）；伴奏最高 100。UI 数字是推子刻度，不是线性声压百分比。

现有历史记录曾确认 GS 在 CH6；现场更换接线后需重新确认。绑定不负责打开 LR、取消静音、调输入 Gain 或处理声场。歌手端不提供这些权限。

## 执行与兼容

API v1 增量增加 audio/audioPolicy 状态、audio_level 和 acappella 操作，OpenAPI 版本 1.1.0。旧客户端可继续点歌；新客户端遇旧中控提示升级。配置兼容旧 singer-gateway.json。

保持 Bearer、局域网与 Origin 限制、单条命令、修订号校验和幂等回执。滑块松手才提交，执行中禁用，断线不自动重放。伴奏检查 mpv 音量回读；麦克风/效果必须 End Sync、相同连接代次、实际参数回读且无 pending 才确认。CUE、转场或另一个 Deck 正在播放时拒绝调音。调音台离线时保留伴奏与清唱能力，禁用硬件控制。

## 验证边界

单元测试验证限幅、白名单、断线/缺少回读、清唱恢复与失败传播。模拟界面验证清唱时钟继续及手机/平板布局。实机联调只使用已暂停歌曲，降低并恢复电脑音乐音量；不发送现场麦克风或 FX 指令。最终全场声音仍需要酒吧现场确认麦克风/FX 绑定并试听。
