# DP448 喇叭布局与输出通道

2026-09-10：底部“专业数字音频处理器”位于设置左侧。

- 复用现场一楼SVG，A-F / 1-8参考网格；位置、朝向、安装高度和测量距离按单只喇叭登记。
- 历史映射来自 `docs/hardware/site-topology.md`：OUT1-2 → 两只舞台全频；OUT7-8 → 四只低音。单只归属和坐标保持未确认，OUT3-6不猜测。
- 左侧8条输出，允许多只喇叭共用一个输出；频率、音量、延时和EQ草稿归属于输出，避免误称每只均可独立处理。
- 布局与草稿存储在 `king.dp448.layout.v1`，导入导出为 `.kingaudio` JSON，格式 `club.king.audio-layout` v1，校验数值、通道与唯一ID。导入不触发硬件。
- 当前DP448离线，没有编造协议驱动和回读。下发禁用，实际分频斜率、限幅和EQ能力待读取；草稿范围不是实机能力声明。
- 已确认连接后，应先备份原AudioCore工程，验证设备身份、协议、输出映射与参数范围，再接入带回读的单输出写入。
- 位置归属与物理间距需用户在平面图标注。距离/343仅显示声程估算，不自动应用延时补偿。

验证：布局模型单元测试，独立浏览器中的放置、朝向、双喇叭共用输出、刷新保留、离线禁止下发和1280px布局通过。未发送DP448、Qu-16或灯光硬件命令。

2026-09-10 用户平面图确认：A1–A6 为悬挂全频，高度约4.3m；B1–B4 为低音；C1–C2 为舞台返听。位置与水平朝向按图估计，距离未测量，单只输出归属仍未确认；不得将 A3–A6、C1–C2 自动分配到 OUT3–6。
