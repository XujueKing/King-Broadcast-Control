# P25 — USB/Qu-16 长时钟漂移校正

## 完成范围

P25 只实现音频后端，不新增或修改 UI。

P24 已经把 USB 输入表计和 Qu-16 TCP 返回表计投射到共享 48 kHz 时间轴。P25 在双流匹配前增加 `ClockDriftEstimator`，用于吸收两套软件时间基准在长时间运行中的缓慢偏移。

校正对象只有 `MeterFrame.framePosition` 证据时间戳：

- 不修改音频样本；
- 不重采样；
- 不拉伸或压缩音频；
- 不启动输出流；
- 不写入 Qu-16。

## 漂移模型与安全边界

首次有效配对建立基础偏移，后续以输入帧位置为自变量估计线性漂移：

```text
predictedOffset = baseOffset + elapsedFrames × driftPpm / 1,000,000
correctedReturn = rawReturn - predictedOffset
```

安全规则：

- 初始基础偏移最大 `2,400` 帧，即 50 ms；
- 可接受漂移速率为 `±200 ppm`；
- 单次预测残差最大 `240` 帧，即 5 ms；
- 连续 3 个残差异常后进入 `unsafe`；
- 漂移速率越界、基础偏移越界或输入时钟倒退立即进入 `unsafe`；
- 5 个有效观测后状态由 `acquiring` 进入 `locked`；
- 连接代次变化或 Qu-16 断线时清空历史，禁止跨连接沿用漂移模型。

进入 `unsafe` 后，双流匹配器立即断开返回证据并失败关闭，不继续使用可疑时间戳。

## 两小时确定性回放

回放条件：

- 48 kHz 时间轴；
- 初始偏移 120 帧；
- 注入稳定 `75 ppm` 漂移；
- 每 10 秒一个观测；
- 总时长 2 小时，共 721 对证据。
