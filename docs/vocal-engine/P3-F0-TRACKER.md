# P3：Realtime F0 Tracker

日期：2026-08-24  
状态：`SIMULATION_PASSED / HARDWARE_PENDING`

## 实现范围

当前模块只观察人声，不改变声音。它以固定内存工作的流式音高跟踪器接收 48 kHz float32 单声道人声，每 128 帧更新一次：

- 默认 F0 范围：70–1000 Hz；
- 分析窗：2048 帧，即 42.67 ms；
- hop：128 帧，即 2.67 ms；
- 4 倍降采样后执行归一化自相关和峰值插值；
- 输出 `voiced`、`f0Hz`、`confidence`、`rmsDbfs` 和样本时间戳；
- RMS 低于 -55 dBFS 时判为无声；
- 支持带正负号的 cents error 计算，供后续 Reference Comparator 使用。

窗口、分析数组与相关数组均在构造时分配，逐块处理不动态扩容、不记录日志，也不执行文件、网络、JSON或模型操作。`pitch.json` 的收集与序列化只存在于非实时模拟层。

## 当前模拟证据

| 用例 | 结果 |
|---|---|
| A4 440 Hz | 平均误差小于 1 Hz |
| 220 Hz、约 ±6 Hz/5 Hz vibrato，含二次谐波 | 连续保持在 190–250 Hz，无八度跳变 |
| 静音 | 全部判断为 unvoiced |
| cents | +50、-25 cents 的符号和数值通过测试 |
| 2 秒类人声信号，196 Hz ±10 Hz | 735/735 voiced，均值 196.32 Hz，范围 186.50–205.52 Hz，平均 confidence 0.9955 |
| 128 帧处理开销 | P99 0.0525 ms，最大 0.0870 ms，无 deadline miss |

以上为当前 RTX 开发机的确定性模拟结果，不是 SLX4 真人话筒或 Qu-16 USB 证据。

## 延迟解释

42.67 ms 是 F0 判断所观察的历史窗口，不是当前音频输出 buffer；P3 仍为 0 dB bypass，所以没有为了等待 F0 而延迟声音。进入 P4 音高修正后，检测响应、修正器 lookahead 与耳返 RTT 必须合并评估。若自然修正需要把整段音频等待完整窗口，将无法满足 `<15 ms RTT`，因此禁止直接把此观察窗口转换成同等音频延迟。
